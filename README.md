
# Super Store Analysis With Excel

## Overview
I analyzed a super store dataset to answer various business questions about sales and customer behavior

### Actions Performed
 - Loaded data to Power Query
 - Cleaned messy data (missing values, duplicates)
 - Built a Star Schema
 - Created a Data Model
- Defined relationships.
- Wrote DAX measures.
- Built an interactive dashboard with slicers.
- Added a reset button.

## Findings
 - East region generated the highest profit.
- Consumer segment produced the highest sales.
- Technology is the top-performing category.
